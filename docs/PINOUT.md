# Pinout

## Motor driver outputs
- M1 PWM = D6, AIN1 = D30, AIN2 = D31
- M2 PWM = D7, BIN1 = D32, BIN2 = D33
- M3 PWM = D8, AIN1 = D35, AIN2 = D36
- M4 PWM = D9, BIN1 = D37, BIN2 = D38

## Encoders
- M1 A = D10, B = D11
- M2 A = D12, B = D13
- M3 A = D14, B = D15
- M4 A = D16, B = D17

## I2C bus
- SDA = D20
- SCL = D21

## VL53L0X
- Front XSHUT = D22
- Right XSHUT = D24
- Left XSHUT = D26

## Servo
- Gripper signal = D5

## QTR-8A
- A0-A7

## Display
- OLED I2C at 0x3C

## Sensor addresses
- TCS34725 = 0x29
- MPU6050 = 0x68
- VL53L0X front = 0x30
- VL53L0X right = 0x31
- VL53L0X left = 0x32
